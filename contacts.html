Главная О нас

О нашем учебном магазине

Данный веб-ресурс создан в качестве практической базы для изучения современного веб-девелопмента: от верстки по БЭМ до интеграции JS-скриптов.

Наши цели и задачи

  • Изучение семантической HTML5-верстки;
  • Освоение БЭМ-методологии и CSS-переменных;
  • Создание многостраничной структуры сайта.

Технологический стек

Технология Назначение
HTML5 Семантическая структура страниц
CSS3 Стилизация, Flexbox, CSS variables
JavaScript (ES6+) Динамика, работа с DOM и формой заказа
